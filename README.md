# Khushory

Offline laundry & dry-clean register — drop-off slips with per-garment item tags and service prices, item-level status flow (received → washing → ready → delivered), printable claim tickets, customer khata + WhatsApp reminders, daily report, work list, rate list print. Encrypted local database, PIN roles, opt-in LAN sharing. No account, no internet.

## Dev
npm install && npm run dev

## Build (Windows .appx)
npm run dist:win

Set `build.appx.identityName` / `publisher` from Partner Center before building for the Store.
